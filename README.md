# Lucas Gabriel — Portfolio

> Personal portfolio of an AI Creative Builder: an in-page AI assistant, project showcase and contact form with Telegram integration.

**Live demo:** https://my-project-zeta-six-16.vercel.app

## ✨ Features

- 🤖 **Built-in AI chat** — visitors talk to an assistant right on the page (OpenRouter, API routes in `src/app/api/chat`)
- 🧩 **Project showcase** — highlights the author's AI apps, games and tools
- 📬 **Contact form** with backend routes (`/api/contact`) and a **Telegram webhook** for messages
- 🎨 Modern responsive UI with Tailwind CSS + shadcn/ui

## 🚀 Stack

Next.js (App Router) · TypeScript · Tailwind CSS + shadcn/ui · Prisma · OpenRouter · Telegram Bot API

## 📦 Run locally

```bash
npm install
# configure env vars (AI key, Telegram bot token)
npm run dev
```
